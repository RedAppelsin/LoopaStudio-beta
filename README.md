# Loopa Studio – testiversio

Loopa Studio on sovellus kirjoneuleen kaavioiden piirtämiseen ja neulomisen seuraamiseen rivi riviltä.

Tämä sivu on testaajia varten. Lataa uusin versio kohdasta **Releases** (oikealla tai sivun alalaidassa).

## Lataus

| Laite | Tiedosto |
|---|---|
| Android-puhelin tai -tabletti | `LoopaStudio.apk` |
| Windows-tietokone | `LoopaStudio-Windows.zip` |

### Android
1. Lataa `LoopaStudio.apk` puhelimella.
2. Avaa ladattu tiedosto. Puhelin voi kysyä lupaa asentaa sovelluksia tästä lähteestä: salli se.
3. Uuden version voi asentaa vanhan päälle, ja kuviot säilyvät.

### Windows
1. Lataa `LoopaStudio-Windows.zip`.
2. Napsauta zipiä hiiren oikealla painikkeella ja valitse **Pura kaikki**. Sovellus ei toimi suoraan zipin sisältä.
3. Avaa purettu kansio ja käynnistä `Loopa Studio.exe`.
4. Jos Windows näyttää varoituksen "Windows suojasi tietokoneesi", valitse **Lisätietoja** ja **Suorita silti**. Varoitus johtuu siitä, että sovellusta ei ole allekirjoitettu.

## Hyvä tietää
- Testiversio toimii 90 päivää ensimmäisestä käynnistyksestä. Jäljellä olevat päivät näkyvät kohdassa Tiedosto > Tietoja.
- Kun jakso päättyy, sovellus tarjoaa vielä varmuuskopion tekemistä, jotta kuviot saa uuteen versioon Palauta-toiminnolla.
- Sovellus ei kerää eikä lähetä tietojasi. Kuviot pysyvät laitteellasi.
- Sovelluksen ohjeen löydät kohdasta Tiedosto > Ohje.

Palautetta otetaan mielellään vastaan!
